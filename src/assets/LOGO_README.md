# Logo Asset Instructions

## Required Image
The login page needs a nurse/clinic logo image.

### File Details
- **Filename**: `nurse-logo.png`
- **Location**: `src/assets/nurse-logo.png`
- **Recommended size**: 180px x 180px (or larger, it will be scaled)
- **Format**: PNG with transparent background preferred
- **Content**: Should match the nurse illustration from your design mockup

### How to Add Your Logo
1. Save your nurse logo image as `nurse-logo.png`
2. Copy it to: `c:\School_Projects\UIC-CMS\my-vue-app\src\assets\`
3. Replace the existing `logo.png` or add alongside it

### Temporary Fallback
Until you add the actual logo, the page will show a broken image icon. The layout and styling are complete and ready.

### Alternative: Use Existing Logo
If you want to use the existing Vue logo temporarily:
- Open `src/components/Login.vue`
- Change line with `nurse-logo.png` to `logo.png`
